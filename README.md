A single 1024×1024 image summing up the world news of Wednesday, 25 November 2026. The six stories it covers: Nvidia chief Jensen Huang apologises to staff at his first all-hands since returning as CEO; NATO sends an AWACS radar plane to Poland after Russian missiles landed there; a Houthi strike hits a tower in Riyadh; a DR Congo Cessna 208 goes missing over the east of the country, with rebels claiming they shot it down; Donald Trump readies a new round of tariffs on trading partners; and a magnitude 5.6 earthquake shakes eastern Nepal near the Tibet border.

The program copies the finished image to `/output/entry.png`. It performs a plain byte-for-byte copy of the bundled PNG, so the output is deterministic — running it twice produces an identical file.
